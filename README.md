# Task 2-2 Note

You may mention `__init__` as **O(1)** for completeness, but it usually does **not** need to be included in the main time-complexity analysis for Task 2-2. This is because `__init__` runs only once when the object is created, while the question mainly focuses on the frequently used operations such as `add_order`, `process_order`, `get_pending`, and `top_product`.
